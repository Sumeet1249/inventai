# InventAI Report Generation Engine

This Domain Microservice acts as the final output stage for the InventAI platform. It converts raw JSON and metrics generated by the Patent, Research, CAD, Physics, and Graph modules into professional, human-readable documents.

## Architecture

This service strictly follows Domain-Driven Design (DDD) and Clean Architecture:

- **`domain/`**: Pydantic models tracking `ReportMetadata`.
- **`templates/`**: Jinja2 templates (Corporate, Academic) for structuring markdown.
- **`exporters/`**: Adapters for `ReportLab` and `python-docx` to convert markdown to PDF/DOCX.
- **`diagrams/`**: Tools to dynamically generate Mermaid/Graphviz charts for injection into the report.
- **`application/`**: Coordinates the report drafting process.
- **`workflows/`**: LangGraph state machine orchestrating AI agents to synthesize the raw JSON data into coherent, professional prose.
- **`api/`**: FastAPI endpoints for triggering report generation and retrieving download links.

## AI Core Integration

This service uses the `ai-core` strictly for **content synthesis**. It does not perform any new scientific or patent analysis; it simply formats and explains the existing data generated by earlier modules.
