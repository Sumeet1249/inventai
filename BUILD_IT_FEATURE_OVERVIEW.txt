┌────────────────────────────────────────────────────────────────────────────┐
│                      BACKEND SERVICES SUMMARY                              │
└────────────────────────────────────────────────────────────────────────────┘

BOM Service (Port 8009)
├── BOMExtractor: Parses circuit/CAD data into component specs
├── BOMGenerator: Creates complete BOMs with quantities
└── Outputs: Component list with auto-categorization

Product Service (Port 8010)
├── ProductProvider: Abstract interface for sellers
├── SearchQueryGenerator: Converts specs to optimized queries
├── ProductMatcher: Scores products (0-100, 80%+ threshold)
└── Outputs: Ranked products with specifications

Shopping Service (Port 8011)
├── ShoppingListGenerator: Creates shopping lists with costs
├── CostOptimizer: Optimizes for cost/delivery/compatibility
└── Outputs: Shopping list with pricing and seller info

Substitution Service (Port 8012)
├── CompatibilityChecker: Voltage, interface, package matching
├── SubstitutionEngine: Finds alternatives with impact assessment
└── Outputs: Compatible substitutes with compatibility scores

├── Add to seller carts (manually)
└── Result: Components ready to buy

Local Development (Docker Compose):
$ docker-compose up bom-service product-service shopping-service substitution-service

Manual Startup:
$ cd services/bom-service && python main.py          # Port 8009
$ cd services/product-service && python main.py      # Port 8010
$ cd services/shopping-service && python main.py     # Port 8011
$ cd services/substitution-service && python main.py # Port 8012

Web Interface:
→ http://localhost:3001/projects/[id]
→ Click "Build It" tab
→ Start component sourcing workflow

Testing:
$ bash BUILD_IT_TEST.sh  # Run automated integration tests
