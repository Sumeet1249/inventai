# InventAI Frontend Platform

This is the Next.js 15 user interface for the InventAI platform. It transforms our powerful AI Orchestrator into a visual, interactive experience suitable for live hackathon demonstrations.

## Architecture

This frontend is built for enterprise scalability and visual impact:

- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript.
- **Styling**: Tailwind CSS + shadcn/ui.
- **State Management**: Zustand (Global) + TanStack Query (Server State).
- __API Client__: `services/api_client.ts` proxies requests to the Python FastAPI microservices.

## Immersive Visualizations

To prove the backend is actually doing work, this frontend includes highly specialized visualizers:

- **`WorkflowVisualizer`**: A React Flow implementation that lights up step-by-step as the Innovation Engine orchestrates Patent, Research, CAD, and Physics modules.
- **`ThreeViewer`**: A wrapper around Three.js that dynamically renders the GLTF files generated by the `cad-service`.
- **`GraphViewer`**: A wrapper around Cytoscape.js that allows users to interactively explore the Neo4j Knowledge Graph generated by the `graph-service`.

## User Journey

1. Land on the Dashboard (`/`).
2. Navigate to Create Project (`/projects/new`) and enter a text description of the invention.
3. The platform transitions to the Live Dashboard (`/projects/[id]`), where the user watches the AI agents execute the workflow in real-time.
4. Finally, the user downloads the AI-drafted Patent and Engineering PDF reports.
